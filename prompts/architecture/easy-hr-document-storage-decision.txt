[INSTRUÇÕES DE AVALIAÇÃO]
- Atribua notas de 0 a 5 por critério (números decimais permitidos, ex.: 4.0).
- Verifique explicitamente:
  (1) Se o aluno compara pelo menos duas alternativas (banco de dados, filesystem local, object storage) com vantagens e desvantagens no contexto do problema.
  (2) Se a decisão escolhida é object storage (ou equivalente como S3, GCS, Azure Blob, MinIO) com metadados no banco relacional.
  (3) Se a justificativa referencia pelo menos dois requisitos funcionais ou não funcionais do enunciado (ex.: não sobrecarregar o banco, crescimento gradual, preservar arquivos em restart).
  (4) Se o aluno reconhece ao menos dois trade-offs concretos da solução escolhida (ex.: dependência de serviço externo, custo variável, gestão de credenciais).
  (5) Se o aluno propõe armazenar metadados no banco relacional (campos como user_id, tipo, data, storage_key ou equivalente).
  (6) Se o aluno descreve algum mecanismo de controle de acesso ao download (URL assinada/presigned URL, rota autenticada ou equivalente).
- Use "evidence" com trechos objetivos da resposta do aluno.
- Consistência: a soma ponderada dos critérios deve refletir a nota "overall".
- Se o aluno escolhe filesystem local sem justificativa sólida, penalize em "decision_justification" pois viola NFR4 (perda de arquivos em restart).
- Se o aluno escolhe salvar binários no banco sem reconhecer o impacto de performance, penalize em "decision_justification" pois viola NFR1.
- Se não menciona nenhum mecanismo de controle de acesso ao download, penalize em "metadata_access_control".
- Para questões de nível easy, não exija CDN, multipart upload, criptografia avançada ou políticas de retenção.
